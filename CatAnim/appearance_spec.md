# 猫プレイヤー 外見デザイン仕様書

## 1. デザイン概要

Unity向け猫プレイヤー3Dモデルの、現時点で確定している**外見・キャラクターデザイン**をまとめた仕様書。

三面図および3Dモデル制作時は、本仕様を外見デザインの基準とする。

---

## 2. 全体コンセプト

| 項目 | 仕様 |
| --- | --- |
| モチーフ | 茶トラ猫 |
| デザイン方向 | リアル寄り |
| キャラクター性 | 元気で親しみやすい |
| 体格 | 標準的な猫 |
| アート表現 | 骨格・体型はリアル寄り、顔の表情は少しトゥーン寄り |
| 毛の長さ | 中毛 |

極端なデフォルメは行わず、実在する猫として自然に見える体型を基本とする。
一方で、ゲームキャラクターとして表情を読み取りやすくするため、顔については若干トゥーン的な表現を取り入れる。

---

## 3. 体型・プロポーション

元の3Dモデル仕様書に従い、以下を基準寸法とする。

| 項目 | 寸法 |
| --- | --- |
| 体長 | 約0.5 m（尻尾を除く） |
| 肩高 | 約0.3 m |
| 尻尾 | 約0.3 m |
| 体格 | 標準 |

細身や丸っこい体型には寄せず、一般的な成猫程度の自然なプロポーションとする。

---

## 4. 毛・模様

### 4.1 基本毛色

- 標準的な茶トラ
- 明るすぎるオレンジや濃すぎる赤茶にはしない
- 茶～オレンジ系をベースとする
- 中毛らしい柔らかな輪郭を持たせる

### 4.2 茶トラ模様

- 全身に自然な縞模様を配置する
- 額のM字模様は**控えめ**
- 縞模様を極端に太くしたり、記号的にしすぎない
- 背面から見ても茶トラであることが認識できる模様にする

### 4.3 白い毛

以下の部位を白くする。

- 口元
- 胸
- 4本の足先

白い部分と茶トラ部分の境界は、機械的な直線ではなく毛並みに沿った自然な形状とする。

---

## 5. 頭・顔

### 5.1 頭部

- 猫として自然な頭蓋・マズル形状
- 極端な丸顔にはしない
- 鼻先は実際の猫程度に前方へ出す
- 骨格はリアル寄り

### 5.2 目

| 項目 | 仕様 |
| --- | --- |
| 形状 | 猫らしいアーモンド形 |
| 表現 | リアルを基準に少しトゥーン寄り |
| 特徴 | オッドアイ |
| 色1 | 緑 |
| 色2 | 黄色 |
| 左右指定 | なし |

緑と黄色の左右配置については現時点では固定しない。

### 5.3 表情

基本状態でも、

- 元気
- 親しみやすい
- 好奇心を感じる

印象を持たせる。

険しい顔、眠そうな顔、過度に幼いマスコット顔には寄せない。

---

## 6. 耳

- 一般的な猫程度のサイズ
- 極端に大きく・小さくしない
- 自然な三角形を基本とする
- 中毛なので耳の付け根や外周に若干の毛束を表現してよい

---

## 7. 尻尾

尻尾はプレイヤーキャラクターを後方から識別するための重要な特徴とする。

| 項目 | 仕様 |
| --- | --- |
| 長さ | 約0.3 m |
| 太さ | 太め |
| 毛量 | ふわふわ |
| 基本形状 | 全体が緩やかなS字 |
| デザイン上の重要度 | 高 |

単純な直線状の尻尾にはせず、ニュートラル状態でも緩いS字のシルエットが読み取れる形状とする。

ただし、アニメーション時に不自然にならない程度の曲率とする。

---

## 8. アクセサリー

### 青色のバンダナ

首元に**青色のバンダナ**を装着する。

- メインカラーは青
- 茶トラのオレンジ系の毛色から明確に識別できる色にする
- 過度に大きくしない
- 四足歩行や首のアニメーションを邪魔しないサイズにする
- 正面・側面だけでなく、後方視点からも一部が認識できる形状が望ましい

具体的な青色の色相・彩度・結び方については未確定。

---

## 9. シルエット上の優先要素

ゲームでは三人称後方視点で表示されるため、以下の順でシルエット上の特徴を重視する。

1. 太くふわふわしたS字の尻尾
2. 中毛による背中・胸周辺の輪郭
3. 猫らしい耳
4. 青色のバンダナ
5. 茶トラ模様
6. 顔・オッドアイ

特に尻尾は、このキャラクターを遠距離から識別する主要な特徴として扱う。

---

## 10. 三面図制作時の条件

三面図では最低限、以下を統一する。

### 正面

- 標準的な猫の体格
- 白い胸
- 白い足先
- 白い口元
- 控えめな額のM字
- 緑・黄色のオッドアイ
- 青色のバンダナ

### 側面

- 体長と肩高の比率
- リアル寄りの頭部・マズル
- 中毛のシルエット
- 太くふわふわした尻尾
- S字の曲がり方
- バンダナの形状

### 背面

- 背中の茶トラ模様
- 後脚の形状
- 白い足先
- 尻尾の付け根
- S字の尻尾
- 中毛による輪郭
- バンダナが後方からどの程度見えるか

三方向で体格・脚の長さ・頭部サイズ・尻尾の付け根位置などが変化しないようにする。

---

## 11. 現時点で未確定の項目

以下については三面図制作時またはその前に必要に応じて決定する。

- オッドアイの左右配置
- バンダナの具体的な青色
- バンダナの結び方・形
- 鼻・肉球の具体的な色
- 茶トラ縞模様の正確な配置
- 毛束の具体的な形状と密度

これらは現在のキャラクターコンセプトを変更しない範囲で調整する。
